## Поиск по смыслу

Заметки проиндексированы локальным qmd (плагин jadlis-memory-search). Коллекции:
{{COLLECTION_LINES}}

- Вопрос по смыслу («где я писал про…», «что я решил о…», проверка дублей перед новой заметкой) → `/memory-search`: typed `lex` + `vec`, обязательный `intent`, `rerank:false`. Plain `query` не использовать.
- Точная строка, имя файла, путь → Grep, не qmd.
- Свежую заметку ищи не раньше, чем {{FRESHNESS}} — индекс обновляется в фоне.
- Добавить или убрать папку → `/memory-search add|remove`; состояние индекса → `/memory-search status`.
